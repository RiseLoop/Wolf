# 🐺 狼人杀模拟器 Pro Max

一个基于 **HTML + JavaScript + TailwindCSS** 的高自由度狼人杀模拟器，支持丰富角色、版型配置与完整游戏流程。

---

## ✨ 项目简介

这是一个用于模拟狼人杀游戏流程的工具，适用于：

* 🎮 线下狼人杀主持辅助
* 🧠 版型测试 / 策略推演
* 📊 计分复盘
* 🧪 自定义角色实验

项目为**纯前端实现**，无需后端，打开即可使用。

---

## 🚀 在线体验

👉 直接下载 `index.html` 后打开浏览器运行
或部署到 GitHub Pages 使用

---

## 🧩 核心功能

### 🎭 角色系统

* 支持 **大量角色（正式角色齐全）**
* 阵营划分：

  * 👼 好人阵营
  * 🐺 狼人阵营
  * 🎭 第三方阵营
* 每个角色具备：

  * 技能类型（夜间 / 白天 / 被动等）
  * 行为逻辑
  * 特殊机制（如自爆、反伤、觉醒等）

---

### ⚙️ 高度自定义配置

* ✔ 自选角色组合
* ✔ 快速版型模板（6人 / 10人 / 12人等）
* ✔ 拼音搜索版型（支持模糊搜索）
* ✔ 分配模式：

  * 顺序分配
  * 随机分配

---

### 👮 规则系统

支持多种规则组合：

* 警长机制：

  * 无警长
  * 单曝吞警徽
  * 双曝吞警徽

* 狼人胜利条件：

  * 数量压制
  * 屠边
  * 屠城

---

### 🎮 游戏流程引擎

完整模拟：

* 🌙 夜晚行动
* 🌅 白天讨论
* 🗳 投票放逐
* 💥 自爆机制
* ⚔️ 技能触发

配有日志系统（类似终端输出），便于游戏复盘

---

### 📊 计分系统

* 支持：

  * 不计分
  * 含/不含投票分
* 自动统计：

  * 阵营胜负
  * 行为得分
* 可查看详细积分记录

---

### 🎨 UI 特性

* 🌌 友好界面
* ✨ 动画效果
* 🖥 类终端日志输出
* 📱 响应式设计

---
